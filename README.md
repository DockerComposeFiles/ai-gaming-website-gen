# HUD Generator

Eine statische Seite (`index.html`), die bei jedem Aufruf ein neues, animiertes Gaming-HUD baut:
zufälliges Layout (BSP-Raster), Farbschema, Schrift, Rahmenstil, Hintergrund und Widget-Mix
(Radar, Oszilloskop, Spektrum, Reaktor-Ringe, Hex-Karte, Telemetrie, Netzwerk, Log, Vitals,
Zielerfassung, Globus, Heatmap, Score, Minimap, Hotbar, Hologramm).

- **R** oder **REROLL**: neues UI generieren
- **SEED LINK**: Link auf genau dieses UI kopieren (`?seed=123`)

Keine Abhängigkeiten – einfach `index.html` im Browser öffnen oder per GitHub Pages ausliefern.
